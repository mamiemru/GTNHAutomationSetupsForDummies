Here is a Setup proposed by FCN.

**This setup only serves Transcendant Nanites, Black Dwarf Nanites, White Dwarf Nanites, Magmatter Nanites, Six Phased Copper Nanites, Gold Nanites, Eternity Nanites and UNiversium Nanites.**

## Nanites Management:
The Level Emiter need the Block of the Nanite ex: Gold Block for gold Nanite, Magmatter Block for Magmatter Nanite and so on...

The output bus is below the controller.

## Logic:
The Wireless Hub on the right is the MainNet. The Stock Replenisher Store Magmatter, Just behind the Dual Interface there is The Interface with patterns.The Wireless Hub on the left is connected to the 2 Wireless Connector on the left side (photo above).

The Wireless Hub on the right is also connected to the Wireless Connector at the back (photo above). There is 2 stocking at 5tick near the Terminal. The input Bus store all Lens and Energised tesseract.

The Controler has a Machine Controller Cover with "Enable with redstone". The other end of the cable is linked to the SFM Redstone Emitter.

Below the Steve factory Inventory cable (Not the redstone emitter) there is an input Hatch UHV (it should be full with magmetter when the system is idle).

## SFM:

Both trigger are set to 1Secondes, On Interval. 

The system on the left Moves Any Fluids from Replenisher to Input Hatch UHV.

The System On the right check if there is at least 4000 Buckets of Magmetter inside the UHV input hatch.
- True (left) set the Redstone Emitter to 15.
- False (right) set the Redstone Emitter to 0.
